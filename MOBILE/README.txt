VITECH GROUP OF COMPANIES — PRESENTATION (MOBILE / OFFLINE POWERPOINT)
=====================================================================

FILE:  Vitech-Group-Presentation.pptx   (140 slides, ~250 MB, includes all
       photos and all 7 videos embedded inside the file)

This is a faithful copy of our web-app presentation, packaged as a single
PowerPoint file so it can be downloaded and viewed on any phone or tablet —
no internet needed once downloaded.


HOW TO OPEN IT ON A PHONE
-------------------------
1. Download / save the file "Vitech-Group-Presentation.pptx" to your phone
   (from WhatsApp, email, Google Drive, etc.). Because it is large (~250 MB),
   use Wi-Fi and let it finish downloading fully.

2. Open it with the FREE "Microsoft PowerPoint" app:
      • Android:  Google Play  ->  "Microsoft PowerPoint"
      • iPhone/iPad:  App Store  ->  "Microsoft PowerPoint"
   (Apple Keynote on iPhone/iPad also opens it.)

3. Tap the play / full-screen (Slide Show) button and swipe left/right to move
   through the slides.


THE VIDEOS
----------
7 slides contain video (factory fly-overs, weld finishing, site erection,
ODC dispatch). In the Microsoft PowerPoint app, tap the video to play it.
Some other viewers (e.g. opening the file inside Google Drive's preview) only
show a still frame — if a video won't play, open the file in the Microsoft
PowerPoint app instead.


NOTES
-----
• The slides are horizontal (landscape, 16:9) — turn your phone sideways for
  the biggest view.
• This is a view-only visual copy of the live deck; the text is not meant to
  be edited here.
• To re-generate this file after the web deck changes:
      node scripts/capture_slides_for_pptx.mjs
      python3 scripts/build_pptx.py
